# online-shop-system
Online Shop System - Software Engineering Project
## Sprint 4 - Shopping Cart

Shopping Cart module implementation.

- Add product to cart
- Update product quantity
- Remove product from cart

## Sprint 5 - Checkout and Payment

Checkout functionality includes:

- Reviewing the order before payment
- Calculating the final order amount
- Connecting to the payment gateway
- Processing successful and failed payments

## Sprint 6 - Order Management

Order management functionality includes:

- Creating an order after successful payment
- Displaying order details
- Viewing order history
- Tracking order status

## Sprint 7 - Inventory Management

Inventory functionality includes:

- Updating product stock
- Checking product availability
- Preventing orders for unavailable products
- Managing stock changes after successful orders

## Sprint 8 - Review and Rating

Review functionality includes:

- Submitting product reviews
- Rating purchased products
- Displaying customer reviews
- Validating review eligibility

## Sprint 9 - Recommendation Engine

Recommendation functionality includes:

- Collecting product interaction data
- Analyzing customer preferences
- Generating product recommendations
- Displaying recommended products

## Sprint 10 - Administration

Administration functionality includes:

- Managing users
- Managing products
- Managing orders
- Managing user roles and permissions
